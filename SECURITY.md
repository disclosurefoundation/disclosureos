# Security reporting

Use GitHub's **Report a vulnerability** action on this repository's Security tab
when it is available. Do not open a public issue containing an exploit, private
records, access tokens or other sensitive information. If private reporting is not
available, use the Disclosure Foundation contact route at
[disclosure.org/contact](https://disclosure.org/contact) to request a private
security channel before sharing technical details.

Include the affected package or portal version, reproduction conditions and the
impact you observed. Distinguish a dependency advisory from a demonstrated
application vulnerability. Use synthetic inputs and do not test against other
people's data or production services without authorization.

The V2 beta is under active development. This project does not currently promise
a response time, security certification or long-term support window. Maintainers
coordinate fixes and disclosure. Releases require dependency review and package,
schema and consumer verification; passing those checks is not a penetration test.
